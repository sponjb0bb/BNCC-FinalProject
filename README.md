# LondoBell
Final Project BNCC Back-End Dev

This project is a Laravel-based web application for managing items and generating invoices.

The application supports two user roles: <br>
Admin <br>
User <br>

**Run Migration and Seeder**
> php artisan migrate:fresh --seed

This command will: <br>
- recreate all tables <br>
- seed category data <br>
- seed admin user account for testing <br>
