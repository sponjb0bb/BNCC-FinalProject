# LondoBell
Final Project BNCC Back-End Dev

This project is a Laravel-based web application for managing items and generating invoices.

The application supports two user roles:
Admin
User

Run Migration and Seeder
php artisan migrate:fresh --seed

This command will:
recreate all tables
seed category data
seed admin user account for testing
